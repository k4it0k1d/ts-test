# Project Guidelines

Use conventional commits for all changes. Run `npm test` before pushing.

## Code Style

- Use TypeScript strict mode
- Prefer `const` over `let`
- Use meaningful variable names

## Testing

All new features must include unit tests. Use `vitest` as the test runner.
